# Веб-мессенджер (Спринт 3)

Одностраничное веб-приложение (SPA) для обмена сообщениями, разработанное без использования сторонних фреймворков на TypeScript и Handlebars.

## Ссылка на развёрнутый проект

👉 **[Открыть мессенджер в Netlify](https://aquamarine-churros-143e24.netlify.app)**

---

## Реализованная функциональность

### Роутинг и навигация
* Реализован клиентский SPA-роутинг на базе **History API** (`Router`, `Route`) с поддержкой кнопок браузера «Назад» и «Вперёд», а также сохранением текущего маршрута при перезагрузке страницы (`F5`).
* Настроены маршруты:
  * `/` — страница авторизации;
  * `/sign-up` — страница регистрации;
  * `/messenger` — список чатов и окно переписки;
  * `/settings` — просмотр и редактирование профиля пользователя;
  * `/404`, `/500` — страницы обработки ошибок.
* Добавлена защита маршрутов (middleware): неавторизованные пользователи перенаправляются на страницу входа `/`, а авторизованные со страниц входа и регистрации — в `/messenger`.
* При переходе между страницами предыдущий компонент корректно удаляется из DOM.

### Интеграция с HTTP API
* Разработан модуль `HTTPTransport` на базе `XMLHttpRequest` и `Promise` с поддержкой методов `GET`, `POST`, `PUT`, `DELETE`, сериализацией `query string` и отправкой `FormData`.
* Подключена работа с API Яндекс Практикума:
  * регистрация, авторизация, получение данных текущего пользователя и выход из системы (`AuthAPI`);
  * редактирование данных профиля, смена пароля, загрузка аватара и поиск пользователей по логину (`UserAPI`);
  * загрузка списка чатов, создание новых чатов, добавление и удаление участников чата (`ChatsAPI`).

> *Чтобы создать новый чат без изменения макета, введите название чата в поле **«Поиск»** в левой панели и нажмите **`Enter`**.

## Стек технологий и архитектура

* **Язык:** TypeScript
* **Сборщик:** Vite
* **Шаблонизатор:** Handlebars
* **Стили:** SCSS (модульная структура по БЭМ)
* **Архитектура:** MVC (`AppModel`, `AppController`, `EventBus`) + компонентный подход на базе базового класса `Block` с реактивным обновлением через `Proxy`.

# Веб-мессенджер (Яндекс.Практикум — Спринт 2)

Клиентское веб-приложение мессенджера, реализованное с использованием компонентного подхода (паттерн MVC), строгой типизации на TypeScript и единой системы валидации форм.

## Ссылка на развёрнутое приложение
- **Netlify:** [Открыть мессенджер](https://aquamarine-churros-143e24.netlify.app)

## Реализованная функциональность
- **Авторизация и регистрация** — формы входа и регистрации с единой валидацией полей по событиям `blur` и `submit` на основе регулярных выражений.
- **Чаты и лента переписки** — список диалогов с поиском, отображение истории сообщений по датам, отправка новых сообщений, модальные окна для добавления и удаления пользователей.
- **Профиль пользователя** — просмотр данных аккаунта, редактирование профиля, смена пароля и загрузка нового аватара.
- **Обработка ошибок** — страницы ошибок `404` и `500`.
- **Сетевой слой** — класс `HTTPTransport` на базе `XMLHttpRequest` для выполнения HTTP-запросов.

## Стек технологий и инструменты
- **TypeScript** — строгая типизация (`noImplicitAny`, `strictNullChecks`, `noUnusedLocals`, `noUnusedParameters`)
- **Vite** — сборка проекта и сервер разработки на порту `3000`
- **Handlebars** — шаблонизация UI-компонентов и страниц
- **SCSS** — препроцессор стилей (методология БЭМ)
- **ESLint** и **Stylelint** — статический анализ TypeScript-кода и SCSS-стилей

## Установка и запуск
1. Установить зависимости:
   ```bash
   npm install
   ```
2. Запустить проект в режиме разработки (`http://localhost:3000`):
   ```bash
   npm run dev
   ```
3. Собрать production-версию и запустить превью-сервер (`http://localhost:3000`):
   ```bash
   npm run start
   ```
4. Запустить проверку типов TypeScript, ESLint и Stylelint:
   ```bash
   npm run lint
   ```
