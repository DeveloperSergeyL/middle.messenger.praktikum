# Веб-мессенджер (Спринт 3)

Одностраничное веб-приложение (SPA) для обмена сообщениями, разработанное без использования сторонних фреймворков на TypeScript и Handlebars.

## Реализованная функциональность

### Роутинг и навигация
* Реализован клиентский SPA-роутинг на базе **History API** (`Router`, `Route`) с поддержкой кнопок браузера «Назад» и «Вперёд», а также сохранением текущего маршрута при перезагрузке страницы (`F5`).
* Настроены маршруты:
  * `/` — страница авторизации;
  * `/sign-up` — страница регистрации;
  * `/messenger` — список чатов и окно переписки;
  * `/settings` — просмотр и редактирование профиля пользователя;
  * `/404`, `/500` — страницы обработки ошибок.
* Добавлена защита маршрутов (middleware): неавторизованные пользователи перенаправляются на страницу входа `/`, а авторизованные со страниц входа и регистрации — в `/messenger`.
* При переходе между страницами предыдущий компонент корректно удаляется из DOM.

### Интеграция с HTTP API
* Разработан модуль `HTTPTransport` на базе `XMLHttpRequest` и `Promise` с поддержкой методов `GET`, `POST`, `PUT`, `DELETE`, сериализацией `query string` и отправкой `FormData`.
* Подключена работа с API Яндекс Практикума:
  * регистрация, авторизация, получение данных текущего пользователя и выход из системы (`AuthAPI`);
  * редактирование данных профиля, смена пароля, загрузка аватара и поиск пользователей по логину (`UserAPI`);
  * загрузка списка чатов, создание новых чатов, добавление и удаление участников чата (`ChatsAPI`).

> *Чтобы создать новый чат без изменения макета, введите название чата в поле **«Поиск»** в левой панели и нажмите **`Enter`**.

## Стек технологий и архитектура

* **Язык:** TypeScript
* **Сборщик:** Vite
* **Шаблонизатор:** Handlebars
* **Стили:** SCSS (модульная структура по БЭМ)
* **Архитектура:** MVC (`AppModel`, `AppController`, `EventBus`) + компонентный подход на базе базового класса `Block` с реактивным обновлением через `Proxy`.

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск локального сервера для разработки
npm run dev

# Проверка типов и сборка продакшен-версии в папку dist
npm run build

# Локальный предпросмотр собранного проекта
npm run preview
```
