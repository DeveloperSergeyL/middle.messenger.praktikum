#  Yandex.Praktikum Messenger Client 

Веб-клиент мессенджера — это одностраничное приложение (SPA), построенное на компонентной **ООП-архитектуре**, шаблонизаторе **Handlebars** и сборщике **Vite**. Интерфейс полностью сверстан по методологии **БЭМ** с использованием препроцессора **Sass (SCSS)** и атомарного дизайна (Atomic Design).

Проект успешно развернут на платформе Netlify и доступен для живого тестирования.

---

## 🛠 Описание проекта и архитектуры

Интерфейс приложения декомпозирован на независимые, изолированные слои в соответствии с принципами чистого кода:

1. **Глобальный диспетчер (`App.js`)**: Хранит всю информацию о текущем состоянии интерфейса и раздаёт её остальным страницам (`this.state`), осуществляет живую фильтрацию чатов и координирует мгновенный перерендеринг нужной страницы.
2. **Компоненты страниц (`src/components/pages/`)**: Изолированные ООП-классы экранов авторизации (**Login**), регистрации (**Signup**), мессенджера (**Messenger**) и личного кабинета (**Profile**). Каждая страница сама отвечает за свои DOM-слушатели.
3. **Атомарный UI (`src/components/ui/`)**: Полностью переиспользуемые строительные «кирпичики» (`input`, `button`, `link`, `avatar`, `modal`), из которых собираются страницы, что гарантирует визуальную консистентность.
4. **Умные хелперы Handlebars**: Самописные функции для сквозного сравнения контекстов (`isEqual`, `isNotEqual`), а также алгоритм автоматической группировки сообщений и вычисления динамической даты в сайдбаре чатов (`formatChatTime`, `lastMessage`).
5. **Изолированные CSS-иконки**: Все вспомогательные графические элементы меню (скрепка, плюс, крестик, геолокация) отрисованы чисто на геометрических CSS/SCSS свойствах и псевдоэлементах без использования тяжелых картинок.

##  Команды для сборки и запуска проекта

Перед началом работы убедитесь, что на вашем компьютере установлена [Node.js](https://nodejs.org/) (рекомендуется версия LTS).

### 1. Установка всех зависимостей
Склонируйте репозиторий и установите пакеты, необходимые для работы Vite, Handlebars и Sass компилятора:
```bash
npm install
```

### 2. Запуск проекта в режиме разработки
Запуск локального сервера разработки с поддержкой **Hot Module Replacement (HMR)**. Проект автоматически откроется в браузере и будет обновляться при каждом сохранении кода:
```bash
npm run start
```
По умолчанию приложение доступно по адресу: `http://localhost:3000/` .

### 3. Сборка проекта для продакшена
Компиляция, минификация и оптимизация всех файлов скриптов, стилей и шаблонов в высокопроизводительный чистый SPA-бандл. Итоговые файлы для деплоя будут сохранены в папку `dist/`:
```bash
npm run build
```

### 4. Локальный предпросмотр продакшен-сборки
Запуск локального сервера для проверки готового скомпилированного бандла из папки `dist/` перед отправкой на хостинг:
```bash
npm run preview
```

##  Валидация форм и логика работы
* **Страница входа / Регистрации**: Формы содержат полную JavaScript-валидацию на пустые поля. При обнаружении ошибок инпуты автоматически подсвечиваются красным цветом и выводят валидационные тексты ошибок в соответствии с макетом.
* **Поиск**: Реализован живой поиск по списку собеседников с сохранением и автоматическим возвратом фокуса в строку ввода при перерисовке DOM.
* **Всплывающие меню и модальные окна**: Вызовы скрепки, верхних трех точек и модалок («Добавить/Удалить пользователя», «Смена аватара») работают на бесконфликтном переключении состояний. Клик в любую пустую область экрана автоматически схлопывает открытые интерфейсы.
