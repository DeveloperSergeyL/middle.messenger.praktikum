# Веб-мессенджер (Яндекс.Практикум — Спринт 2)

Клиентское веб-приложение мессенджера, реализованное с использованием компонентного подхода (паттерн MVC), строгой типизации на TypeScript и единой системы валидации форм.

## Ссылка на развёрнутое приложение
- **Netlify:** [Открыть мессенджер](https://netlify.app)

## Реализованная функциональность
- **Авторизация и регистрация** — формы входа и регистрации с единой валидацией полей по событиям `blur` и `submit` на основе регулярных выражений.
- **Чаты и лента переписки** — список диалогов с поиском, отображение истории сообщений по датам, отправка новых сообщений, модальные окна для добавления и удаления пользователей.
- **Профиль пользователя** — просмотр данных аккаунта, редактирование профиля, смена пароля и загрузка нового аватара.
- **Обработка ошибок** — страницы ошибок `404` и `500`.
- **Сетевой слой** — класс `HTTPTransport` на базе `XMLHttpRequest` для выполнения HTTP-запросов.

## Стек технологий и инструменты
- **TypeScript** — строгая типизация (`noImplicitAny`, `strictNullChecks`, `noUnusedLocals`, `noUnusedParameters`)
- **Vite** — сборка проекта и сервер разработки на порту `3000`
- **Handlebars** — шаблонизация UI-компонентов и страниц
- **SCSS** — препроцессор стилей (методология БЭМ)
- **ESLint** и **Stylelint** — статический анализ TypeScript-кода и SCSS-стилей

## Установка и запуск
1. Установить зависимости:
   ```bash
   npm install
   ```
2. Запустить проект в режиме разработки (`http://localhost:3000`):
   ```bash
   npm run dev
   ```
3. Собрать production-версию и запустить превью-сервер (`http://localhost:3000`):
   ```bash
   npm run start
   ```
4. Запустить проверку типов TypeScript, ESLint и Stylelint:
   ```bash
   npm run lint
   ```
